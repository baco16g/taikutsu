# UX仕様

現在の実装にもとづく、画面構成と操作の決まりです。固有名詞と用語の扱いは [用語集](./glossary) を参照してください。

## 1. 画面構成

アプリは `/` の1ページだけで、イントロ → 戦闘 → 撃破 → ギャラリーの順に、同じ枠の中で画面が切り替わります。タ・イクツはイントロから戦闘まで同じ1体が表示され続け、画面が切り替わっても途切れずに移動します。

レイアウトは、枠の内側の幅で2種類に切り替わります。

| レイアウト | 条件                    | 並び方                                                                                 |
| ---------- | ----------------------- | -------------------------------------------------------------------------------------- |
| 横並び     | 枠の内側の幅が800px以上 | イントロは文字とタ・イクツを左右に、戦闘はタ・イクツと HP を左、スキル一覧を右下に置く |
| 縦積み     | 枠の内側の幅が800px未満 | 見出し・タ・イクツ・文章・操作を上から順に並べる                                       |

横並びの枠の高さは画面の高さに合わせて決まります（最小640px、最大880px）。戦闘画面でスキル一覧がその高さに収まらないときだけ、枠の上端を動かさずに、枠を下へ伸ばします。そのため、横に広いわりに背の低い画面では、戦闘中にページを少しスクロールできることがあります。

## 2. 全画面に共通する決まり

- 効果音のボタンは、画面の右下に固定して表示します。初期状態はオフで、押すたびにオン・オフが切り替わります。ボタンは、押された状態（`aria-pressed`）と、次に押すとどうなるか（「サウンドをオンにする」など）をスクリーンリーダーに伝えます。ブラウザの決まりにより、ユーザーが一度操作するまでは音は鳴りません。
- 次の3つの場面で、スクリーンリーダー向けに状況を読み上げます。
  - 戦闘が始まったとき: 「タ・イクツが現れました。スキルを選んでください。」
  - タ・イクツを倒したとき: 「タ・イクツを倒した。退屈の向こうに、まだ知らない遊びがある。」
  - ギャラリーが表示されたとき: 「タ・イクツを撃破しました。ゲームギャラリーを表示しています。」
- 戦闘が始まると戦闘画面の見出しへ、ギャラリーが表示されるとギャラリーの見出しへ、フォーカスを移します。
- 画面の切り替えの途中は、切り替え前後の画面を操作できない状態（`inert`）にします。
- 端末の設定で動きを減らしている場合の表示は、§7 にまとめています。

## 3. イントロ

- 見出し「退屈を、たおせ！」、タ・イクツの肩書きと名前（「退屈のかたまり」「タ・イクツ」）、紹介文、「たたかう」ボタンを表示します。横並びのときは、見出しの上に「PLAY OUTSIDE THE LINES.」を表示します。
- 背景には街の線画を薄く表示し、横並びのときは枠の左下に地図データのクレジット（「© OpenStreetMap contributors」）を表示します。
- 表示を始めると、細かな粒がタ・イクツの位置へ集まり、タ・イクツの姿が少しずつ現れます。
- 「たたかう」は、タ・イクツが現れきる前にも押せます。そのときは出現の演出を早送りしてから戦闘へ進みます。一度押すとボタンは無効になります。
- マウスなどでホバーできる端末では、「たたかう」にポインタを重ねると効果音（オンのとき）が鳴ります。
- 「たたかう」を押すと、イントロの文字がフェードアウトし、タ・イクツが戦闘の位置へ移動しながら、戦闘画面がフェードインします。移動の途中でウィンドウの大きさが変わったときは、演出を飛ばして戦闘画面の状態へすぐ進みます。

## 4. 戦闘

### 表示

- 見出し「退屈を、たおせ！」（横並びのときは上に「A SMALL CHANGE IN A BORING WORLD.」）、タ・イクツ、肩書きと名前、HP の目盛り（5つ）、スキル一覧、「ほかのスキルを見る」を表示します。
- HP の目盛りは、「HP 3 / 5」のように残りの値をスクリーンリーダーに伝えます。攻撃の回数はスキル一覧には表示せず、HP の目盛りだけで残りを示します。
- スキル一覧には常に6つのスキルを、番号・アイコン・名前・説明の順に並べます。説明は省略せず、必要な行数だけ折り返します。
- 選んでいる行には、黒い帯が重なります。攻撃を受け付けている間、帯はゆっくり明滅します。

### スキルの選び方

| 操作の手段                     | 行を選ぶ                                     | 攻撃する                                                         |
| ------------------------------ | -------------------------------------------- | ---------------------------------------------------------------- |
| マウスなど（ホバーできる端末） | 行にポインタを重ねる                         | 行をクリックする                                                 |
| タッチ（ホバーできない端末）   | 行を1回タップする                            | 選んでいる行をもう一度タップする（別の行に移ると選択をやり直す） |
| キーボード                     | 上下の矢印キー（先頭と末尾はつながっている） | Enter キーまたはスペースキー                                     |

- 新しい6つが表示された直後は、マウスを動かすまで選択は先頭の行のままです。たまたまポインタの下にある行は選ばれません。
- カーソルが動くと効果音（オンのとき）が鳴ります。

### 攻撃

1. スキルを確定すると、その場で入力を受け付けなくなり、攻撃の効果音が鳴ります。音の高さはスキルごとに決まっています。
2. 帯が一瞬弾み、少し間をおいて、そのスキルのアイコンがタ・イクツへ飛びます。
3. アイコンが当たった瞬間に HP の目盛りが1つ減り、当たった音が鳴ります。当たった音は、1回目から5回目に向けて少しずつ大きく、高くなります。
4. タ・イクツは当たった位置から破片を散らし、HP の段階に応じた形へ変わります。前の攻撃の変形がまだ終わっていないうちに次の攻撃が当たったときは、前の変形を最後まで進めてから次の変形を始めます。
5. 次の6つが表示され、入力を再び受け付けます。次の6つには、まだ一度も表示されていないスキルを優先して出します。攻撃を確定したときにフォーカスがスキル一覧にあった場合は、新しい一覧の先頭の行にフォーカスを移します。

### ほかのスキルを見る

- 表示中の6つを、攻撃の回数を使わずに入れ替えます。回数の制限はありません。
- まだ一度も表示されていないスキルを優先して出し、表示中の6つは次の6つに含めません。
- 一度攻撃に使ったスキルは、同じ戦闘の中では二度と表示しません。

### タ・イクツ

- 攻撃を受けていない間は、呼吸するようにゆっくり揺れ、上下に浮かびます。
- ポインタを重ねると、揺れが大きく速くなり、少し膨らみます。

## 5. 撃破

- 5回目の攻撃が当たると、タ・イクツは穴が開くように崩れて消えます。崩れきった時点で撃破とみなし、読み上げで知らせます。
- 5回目の攻撃が当たった時点で、スキル一覧と「ほかのスキルを見る」は操作できなくなります。撃破すると、HP の表示とスキル一覧はフェードアウトし、タ・イクツがいた辺りに破片が残ります。
- 約0.8秒後、3枚のシートが右下から左上へ斜めに画面を覆い、覆った裏でギャラリーへ切り替えてから、シートが外れます。この間はページのスクロールを止めます。
- シートの動きの途中でウィンドウの大きさが変わったり、タブが非表示になったりしたときは、演出を飛ばしてギャラリーの状態へすぐ進みます。

## 6. ギャラリー

### 表示

- 見出し「退屈はもう終わり。次に遊ぶゲームを、見つけにいこう！」と、「あなたが選んだ5つのスキルから、10作品を推薦しました。」を表示します。
- 10作品のカードを、正面の1枚を中心に立体的な輪のように並べます。正面から遠いカードほど小さく薄く表示し、ある程度離れたカードは操作と読み上げの対象から外します。
- 表示を始めると、カードが中央から輪の位置へ広がります。この演出が終わるまで、作品の切り替え操作は受け付けません。

### 作品の切り替え

- 左右の矢印ボタン（「前の作品」「次の作品」）、カードの下の点、カードのスワイプ、キーボードの左右の矢印キーで切り替えます。最後の作品の次は最初の作品に戻ります。
- 正面以外のカードを押すと、そのカードが正面に来ます。
- 正面の作品か正面以外のカードにフォーカスがある状態で作品を切り替えると、フォーカスは新しい正面の作品に移ります。
- 画面幅 720px 以下では、作品を選ぶ点を矢印ボタンの下の行に並べます。359px 以下では、点を5個ずつ2行に並べます。
- 切り替えるたびに「3 / 10枚目: （作品名） を表示中」のように読み上げます。

### 作品の説明と販売ページ

- 正面の作品について、名前、キャッチコピー、紹介文を表示します。
- 選んだスキルと強く結びつく作品では、結びつくスキルごとに「あなたが選んだスキル」と「このゲームで楽しめること」（そのスキルの説明）を表示します。結びつくスキルがない作品では、「こんな遊びもどう？ 選んだスキルとは少し違う体験が楽しめるゲームです。」と表示します。
- 正面のカードと「ゲームの詳細を見る」は、その作品の販売ページを新しいタブで開きます。スクリーンリーダーには「（販売ページを別タブで開きます）」と伝えます。スワイプした直後のタップでは開きません。
- 「もう一度たたかう」を押すと、イントロからやり直します。

### 画像の読み込み

- ゲームの画像は、外部のゲーム販売サイトから読み込みます。
- 最初は正面と隣のカードの画像だけを読み込み、それらが読み込み終わってから（失敗した場合も含む）、残りのカードの画像を読み込みます。
- 画像を読み込めなかったカードには、画像の代わりにゲーム名を表示します。

## 7. 動きを減らす設定のとき

端末の設定（`prefers-reduced-motion: reduce`）で動きを減らしている場合は、次のように表示します。遊び方とルールは変わりません。

- イントロの粒の演出を省き、タ・イクツをすぐに表示します。
- タ・イクツの揺れ、浮遊、ポインタを重ねたときの反応を止めます。被弾の変形は短く、弾まない動きにします。
- 戦闘位置への移動、帯の移動、アイコンの飛翔、スキル一覧の表示は、動かさずにすぐ切り替えます。帯の明滅も止めます。
- 撃破後の画面の切り替えは、斜めのシートではなく短いフェードにします。
- ギャラリーのカードが広がる演出と、作品の説明の切り替えの動きを省きます。
