# 「退屈を、たおせ！」のしくみ

開発者以外の方向けに、アプリの動きと決まりごと、2026-10-14 の内部整理（リファクタリング）と不具合の修正の影響をまとめた資料です。コードの構成は [architecture.md](architecture.md) にあります。

特に印のない記述は、プログラムを読んで確かめた内容です。そのうえで、次のように書き分けています。

- **確認済み**: 実際に動かしても確かめたこと
- **推測**: 根拠はあるが確かめきれていないこと

## 1. どんなアプリか

ブラウザで遊ぶ、1画面だけの小さなゲームです。「退屈の化身」タ・イクツに、気になるスキル（遊び方の好み。例:「スピードダッシュ」「クックマスター」）を5つぶつけて倒します。倒すと、選んだスキルをもとに「次に遊ぶゲーム」が10作品おすすめされます。

ログインや会員登録はありません。サーバーとの通信もありません。

## 2. 画面の流れ

1. イントロ: 粒が集まってタ・イクツが現れます。「たたかう」を押すと、タ・イクツが戦闘の位置へ移動します。現れきる前に押した場合も受け付け、出現の演出を早送りします。
2. 戦闘: 画面の右側（スマートフォンでは下側）に、スキルが6つ並びます。1つ選ぶとアイコンがタ・イクツへ飛び、HP（体力。5つの目盛り）が1つ減ります。
3. 撃破: 5回当てるとタ・イクツが崩れ、破片が残ります。約0.8秒後、斜めのシートが画面を覆います。
4. ギャラリー: シートが外れると、おすすめの10作品が回転する棚のように並びます。左右の矢印、下の点、スワイプ（指で横に払う操作）、キーボードの左右キーで作品を切り替えられます。
5. もう一度たたかう: ギャラリーのボタンを押すと、イントロからやり直します。

## 3. 戦闘のルール

| 項目                             | 決まりごと                                                                                                  |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| スキルの数                       | 全27種類。画面には常に6つ表示される                                                                         |
| 選べる回数                       | 5回。5回当てるとタ・イクツを倒せる                                                                          |
| 使ったスキル                     | 同じ戦闘の中では二度と出てこない                                                                            |
| 「ほかのスキルを見る」           | 表示中の6つを入れ替える。攻撃の回数は減らず、何度でも押せる。まだ一度も表示されていないスキルが優先して出る |
| 1回の攻撃の流れ                  | 選んだ瞬間に入力を受け付けなくなり、アイコンが届くとHPが減り、次の6つが並ぶ                                 |
| スマートフォンなど（タッチ操作） | 1回目のタップで選択、同じ行をもう一度タップすると攻撃。誤って攻撃しないため                                 |
| マウス                           | 行にカーソルを乗せると選択され、クリックで攻撃                                                              |
| キーボード                       | 上下の矢印キーで行を移動（先頭と末尾はつながっている）、Enter キーまたはスペースキーで攻撃                  |

## 4. おすすめのゲームの決まり方

- おすすめは10作品です。
- 最大5作品は、選んだスキルと「強く結びつく」作品です。どの作品がどのスキルと強く結びつくかは、ゲームごとのデータにあらかじめ書かれています。選んだスキルのそれぞれに1作品ずつ行き渡るよう、順番に選びます。
- 残りは、選んだどのスキルとも強くは結びつかない作品です。新しい出会いのために、あえて混ぜています。
- 同じ5つのスキルを選べば、選んだ順番に関係なく、同じ10作品が同じ並びで出ます。
- 作品の説明欄には、結びつくスキルがある場合は「あなたが選んだスキル」と「このゲームで楽しめること」を表示します。ない場合は「こんな遊びもどう？」と表示します。
- 「ゲームの詳細を見る」を押すと、そのゲームの販売ページが新しいタブで開きます。

## 5. 入力と出力

| 入力（プレイヤーがすること）   | 出力（アプリが返すもの）                    |
| ------------------------------ | ------------------------------------------- |
| 「たたかう」を押す             | 戦闘画面に切り替わる                        |
| スキルを選ぶ（5回）            | HP が減り、5回目で撃破の演出が出る          |
| 「ほかのスキルを見る」を押す   | 表示中のスキルが入れ替わる                  |
| ギャラリーで作品を切り替える   | 作品の説明欄が切り替わる                    |
| 「ゲームの詳細を見る」を押す   | 外部の販売ページが新しいタブで開く          |
| 右下のスピーカーのボタンを押す | 効果音のオン/オフが切り替わる（最初はオフ） |
| 「もう一度たたかう」を押す     | イントロに戻る                              |

## 6. 特別な場合の動き

- 端末の設定で動きを減らす機能（iPhone の「視差効果を減らす」など）をオンにしている場合は、大きな動きを省き、短いフェードなどに置き換えます。遊び方やルールは変わりません。
- 効果音は最初はオフです。オンにしても、ブラウザの決まりにより、ユーザーが一度操作するまでは鳴りません。
- ゲーム画像を読み込めなかった作品は、画像の代わりにゲーム名を表示します。
- 画面の切り替えの途中でウィンドウの大きさを変えると、途中の演出を飛ばして、切り替え後の状態へすぐ進みます。
- 画面の読み上げソフト（スクリーンリーダー）向けに、「タ・イクツが現れました」「タ・イクツを倒した」「ゲームギャラリーを表示しています」の3つの場面で状況を読み上げます。戦闘とギャラリーの開始時には、操作の焦点（フォーカス）を見出しへ移します。

## 7. 情報の出どころ・保存先・関係する外部のしくみ

| 種類                                          | 出どころ・保存先                                                                                          |
| --------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| スキルの一覧（27種類）                        | アプリに同梱しているファイル `data/specialMoves.json`                                                     |
| ゲームの一覧（399作品）と、スキルとの結びつき | アプリに同梱しているファイル `data/gameIntros.json`                                                       |
| ゲームの画像                                  | 外部のゲーム販売サイトから、その都度読み込む（URL は `data/gameIntros.json` に記載）                      |
| 販売ページへのリンク                          | 同じ外部のゲーム販売サイト                                                                                |
| 効果音                                        | ブラウザの中で合成する（音声ファイルはない）                                                              |
| 背景の街の絵                                  | アプリに同梱。OpenStreetMap（誰でも使える地図データ）をもとにした絵なので、表示中は左下にクレジットを出す |
| プレイの記録                                  | どこにも保存しない。ページを再読み込みすると最初からになる                                                |
| 公開先                                        | GitHub Pages（GitHub の Web ページ公開サービス）。`main` ブランチへの反映で自動的に公開される             |

`docs/research/` には調査用のより詳しいデータがありますが、アプリでは使っていません。

## 8. 今回の内部整理と不具合の修正で変わったこと

作業は2段階で行いました。まずプログラムの整理（動きを変えないリファクタリング）を行い、その後、整理の途中で見つけた不具合を直しました。

### 8.1 プログラムの整理

整理そのものによる、プレイヤーから見た変化はありません。画面、文言、ルール、操作、おすすめの結果は変わりません（確認済み）。確かめるために、整理の前と後で次の3つを比べました。

- 同じ操作をしたときの表示内容、読み上げ、おすすめの10作品（パソコン幅、スマートフォン幅、動きを減らす設定の3通り）
- 画面上のすべての部品の位置、大きさ、文字の書式
- 撃破の演出から画面の切り替えが始まるまでの時間

内部のタイミングを1か所だけ、わずかに変えました。撃破から画面の切り替えが始まるまでの待ち時間（約0.8秒）を数え始める時点を、内部の処理で1段階後ろにずらしています。実測した差は、計測の誤差（約0.016秒）の範囲に収まりました。

中身の変更は、プログラムの整理だけです。画面ごとの部品を分け、同じ情報を何か所でも数えていた部分を1か所にまとめました。変更が必要になったときに、どこを直せばよいかが分かりやすくなっています。

### 8.2 直した不具合

次の2つは、プレイヤーから見える動きが変わります。

1. とても素早く連続して攻撃すると、HP は0になるのにタ・イクツを倒しきれず、先へ進めなくなることがありました（確認済み）。前の攻撃の演出が終わる前に次の攻撃が届くと、タ・イクツ側がその攻撃を数えていなかったためです。今は、前の演出を最後まで進めてから次の攻撃の演出を始めるので、何回連続で当てても必ず倒せます。普通の速さで遊ぶときの動きは変わりません。
2. 戦闘画面で、選んでいる行の帯がゆっくり明滅する演出は、本来は途切れずに続く設計でした。ところが実際には、カーソルを動かすたびに最初からやり直しになっていました（確認済み）。今は、カーソルを動かしても途切れません。

ほかに、目に見えない無駄な処理の削除と、テストの修正・追加も行いました。

### 8.3 運用への影響

ありません。公開の手順（`main` への反映で自動公開）とその設定は変えていません。

## 9. 分かっている制限と、決めてほしいこと

1. ゲームの画像とリンクは外部のサイトに頼っています。先方で URL が変わると、画像が表示されなかったり、リンクが切れたりします。今は、それを自動で検知するしくみはありません。
   - **決めてほしいこと**: データの更新や、リンク切れの点検を誰がいつ行うか。
2. 確認できていない環境があります。実機のスマートフォンでの操作、画面の読み上げソフトでの実際の読み上げ、Safari と Firefox での表示、効果音の実際の鳴り方は、今回は確かめていません。
3. スキルの数「5」に関係する決まり（攻撃の回数、タ・イクツの体力の段階、おすすめの枠、イントロの文言）は連動しています。回数を変える場合は、あわせて見直す必要があります。攻撃の回数と体力の段階の数が一致していることは、自動テストで確かめています。
4. アプリのプログラムは約1.1MB（圧縮して約340KB）あり、最初の読み込みで一度に取得します。大部分はゲームの一覧データです。ギャラリーを後から読み込む形にすれば軽くできますが、撃破後に通信が発生し、通信に失敗したときの表示も必要になるため、今回は見送りました。
