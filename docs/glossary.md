# 用語集

ドキュメントとコードで共通して使う、このアプリ固有の用語です。ここにない言葉は、一般的な意味で使っています。コード上の名前がある用語は、その名前も示しています。

## 作品と登場するもの

| 用語             | 意味                                                                               | コード上の名前                                                          |
| ---------------- | ---------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| 退屈を、たおせ！ | このアプリの名前                                                                   | リポジトリ名は `taikutsu`                                               |
| タ・イクツ       | 退屈の化身として登場する敵。肩書きは「退屈のかたまり」                             | `TaikutsuCreature`、`features/taikutsu`                                 |
| スキル           | 遊ぶ人が選ぶ、ゲームを通じて味わいたい体験。戦闘ではタ・イクツへの攻撃の手段になる | `move`（`MoveEntry`、`SpecialMove`）、データは `data/specialMoves.json` |
| HP               | タ・イクツの残りの体力。5から始まり、着弾のたびに1減る。0で撃破                    | `Hp`、`hpRemaining`                                                     |

## 画面

| 用語                       | 意味                                                                                           | コード上の名前                             |
| -------------------------- | ---------------------------------------------------------------------------------------------- | ------------------------------------------ |
| イントロ                   | 最初の画面。タ・イクツが現れ、「たたかう」で戦闘を始める                                       | `IntroScreen`                              |
| 戦闘画面                   | スキルを選んでタ・イクツを攻撃する画面                                                         | `BattleScreen`                             |
| スキル一覧                 | 戦闘画面に並ぶ6つのスキル。「コマンドメニュー」とも呼ぶ                                        | `CommandMenu`                              |
| ギャラリー                 | 撃破の後に、選んだスキルをもとに10作品を紹介する画面                                           | `GameGallery`                              |
| ギャラリーの読み込みエラー | ギャラリーを読み込めなかったときに、ギャラリーの代わりに出す表示。ページの再読み込みを案内する | `GalleryLoadError`                         |
| 画面遷移のシート           | 戦闘画面からギャラリーへ切り替えるときに画面を覆う3枚のシート                                  | `RevealTransition`                         |
| 枠                         | すべての画面を囲む、紙のような枠と背景の装飾                                                   | `WorldFrame`（枠の要素は World Container） |
| 横並び / 縦積み            | 枠の内側の幅が800px以上のときのレイアウトと、800px未満のときのレイアウト                       | CSS のコンテナクエリ `world-outer`         |

## 戦闘

| 用語               | 意味                                                                                                              | コード上の名前                          |
| ------------------ | ----------------------------------------------------------------------------------------------------------------- | --------------------------------------- |
| 着弾               | 攻撃のアイコンがタ・イクツに当たること。着弾したスキルが「選んだスキル」として記録される                          | `onImpact`、`LandedMove`、`landedMoves` |
| 攻撃上限           | 1回の戦闘で攻撃できる回数（5回）。タ・イクツの最大 HP と同じ                                                      | `ATTACK_LIMIT`                          |
| ほかのスキルを見る | 攻撃の回数を使わずに、表示中の6つを入れ替える操作                                                                 | `reroll`                                |
| 使用済み / 未表示  | 攻撃に使ったスキル（同じ戦闘で二度と出ない）と、まだ一度も表示していないスキル（次の6つを選ぶときに優先して出る） | `usedIds`、`unseenIds`                  |
| 選択帯             | スキル一覧で、選んでいる行に重なる黒い帯                                                                          | `band`                                  |
| 撃破               | タ・イクツが HP0 の形まで崩れきること                                                                             | `stage === 'defeated'`                  |
| 立ち位置の目印     | タ・イクツを表示する位置と大きさを示す、画面ごとの空の要素。タ・イクツ本体はこの位置へ移動して重なる              | `dock`、`creatureDockRef`               |

## 推薦

| 用語          | 意味                                                                                             | コード上の名前              |
| ------------- | ------------------------------------------------------------------------------------------------ | --------------------------- |
| 結びつき      | ゲームとスキルの関係。強さは `strong`（強い）か `medium`（中程度）。推薦には `strong` だけを使う | `relatedMoves`、`relevance` |
| strong-tie 枠 | ギャラリーの10作品のうち、選んだスキルと `strong` で結びつくゲームを入れる枠（最大5作品）        | `STRONG_TIE_TARGET`         |
| discovery 枠  | ギャラリーの10作品のうち、選んだどのスキルとも `strong` で結びつかないゲームを入れる枠           | `recommend.ts` の discovery |

## 進行

### イントロのフェーズ（`IntroPhase`）

| 値         | 意味                                         |
| ---------- | -------------------------------------------- |
| `arrival`  | タ・イクツが現れている途中                   |
| `ready`    | 現れ終わり、「たたかう」を待っている         |
| `depart`   | イントロの文字がフェードアウトしている       |
| `moving`   | タ・イクツが戦闘の位置へ移動している         |
| `settling` | 移動を終え、戦闘画面に落ち着くまでの短い間   |
| `battle`   | 戦闘画面（撃破後、ギャラリーの表示中も含む） |

### 進行段階（`SessionStage`）

| 値           | 意味                                                                   |
| ------------ | ---------------------------------------------------------------------- |
| `undefeated` | まだ倒していない（イントロ中も含む）                                   |
| `defeated`   | 倒した。破片を見せながら、少しの時間とギャラリーの読み込みの完了を待つ |
| `covering`   | 画面遷移のシートが戦闘画面を覆っていく                                 |
| `uncovering` | 覆った裏でギャラリーに差し替え済み。シートが外れていく                 |
| `gallery`    | ギャラリーを操作できる                                                 |

## その他

| 用語                   | 意味                                                                                                                         |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 動きを減らす設定       | 端末やブラウザの設定で、画面の動きを減らすよう求めている状態（`prefers-reduced-motion: reduce`）。このときは大きな動きを省く |
| 外部のゲーム販売サイト | ゲームの画像の読み込み元と、販売ページへのリンク先                                                                           |
